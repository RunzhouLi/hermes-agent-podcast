# EP08 — Heuristic Mining (启发式挖掘)

> BPI Course Podcast · RWTH Aachen SS 2026 · Prof. Wil van der Aalst 第八讲
> 中心类比：考古学与地层发掘 — 频率是硬通货

## 本集概要

Alpha 算法很优雅，但有一个致命弱点：**一丁点噪声就崩溃。** 真实世界的事件日志永远不可能是完美的——总有异常、缺失、错误。我们需要一种能容忍噪声的算法。

**启发式挖掘（Heuristic Mining）** 的核心理念很简单：不要只问"有没有"，要问"有多少次"。
就像考古学家无法亲眼看到古人生活，只能靠统计文物出土频率来推断文化关联——
频率，是区分"真实因果关系"和"随机噪音"的唯一硬证据。

本集分两个阶段：

**Phase 1 — 构建依赖图**
- 数 "直接跟随" 次数：|a>_L b|
- 计算依赖度：|a⇒_L b| = (|a>_L b| - |b>_L a|) / (|a>_L b| + |b>_L a| + 1)
- 这个 [-1, 1] 的公式本质上在问："a 到 b 是单向的吗？且低频的我不信。"
- 双阈值过滤：频率阈值挡住偶然噪声，依赖阈值挡住并行假象——两道门都过，才画一条弧
- 五类模式识别：序列、XOR分叉/汇合、AND分叉/汇合、循环

**Phase 2 — 学习 C-net 绑定**
- 依赖图只有箭头，没有"二选一"还是"都要来"的规矩
- 滑动窗口法：在同一 trace 上滑一个固定大小的窗口，统计窗口内共同出现的活动
- 把这些共现组合变成 C-net 的输入/输出绑定——就像研究同一地层内几厘米范围内的文物组合
- 最终生成一份完整的"文化层序报告"：哪个活动可以被哪些前置条件触发

集末用学过的披萨流程实战验证：启发式挖掘纯靠频率，自己数出了"三料齐全才吃（2³=8）"的业务规则——完美拟合。

## 关键术语

| 中文 | English | 简述 |
|------|---------|------|
| 启发式挖掘 | Heuristic Mining | 用频率统计代替精确集合判断，容忍噪声的过程发现算法 |
| 直接跟随 | Direct Succession | b 紧跟在 a 之后出现的次数 |
| 依赖度 | Dependency Measure | 归一化的因果强度 [-1,1]，正=因果，近0=并行/选择 |
| 频率阈值 | Frequency Threshold | 最低原始出现次数，挡住偶然噪声 |
| 依赖阈值 | Dependency Threshold | 最低依赖度，挡住并行假象 |
| 滑动窗口 | Sliding Window | 在 trace 上滑动固定大小窗口，统计共现活动以生成绑定 |
| 输入/输出绑定 | Input/Output Binding | C-net 中每个活动的前置/后置活动集合 |
