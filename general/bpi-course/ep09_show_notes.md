# EP09 — Region-Based Mining (基于区域的挖掘)

> BPI Course Podcast · RWTH Aachen SS 2026 · Prof. Wil van der Aalst 第九讲
> 中心类比：卫星制图与分色 — 先看清全貌，再分色描线

## 本集概要

Alpha 数关系，Heuristic 数频率——还有第三种完全不同的思路：**先把整个流程拍成一张状态全景图。**

**基于区域的挖掘（Region-Based Mining）** 从不数活动两两之间的局部关系。
它先把日志展开成一张完整的**迁移系统（Transition System）**——每个状态代表"到目前为止看到了什么"，
每条边是一次活动。这就像卫星从轨道上给流程拍了一张高分辨率影像。

然后进入两阶段：

**Phase 1 — 拍摄影像**
- 状态 = 历史的抽象。三种粒度：序列（精确路径）、集合（哪些活动出现了）、多重集（每个活动几次）
- n-tail 截断：只看最近 n 步。1-tail 就是"只看上一步"
- 分辨率的选择本质是在过拟合（图碎成沙）和欠拟合（图糊成块）之间找平衡

**Phase 2 — 分色与矢量化**
- **区域（Region）**：一组状态，其中每个活动的所有箭头"意见一致"——要么全进入、要么全离开、要么全不碰
- **极小区域**：不可再分的非平凡区域，每一个对应 Petri 网的一个库所
- 从 1026 个状态的乱麻中，区域挖掘还原出十个并发活动的极简 Petri 网

**但有一个问题：模拟够，互模拟不够。** 区域挖掘保证模型能跟上日志（模拟），
但它可能多画了实际没有的路（欠拟合）。补救手术是**标签拆分（Label Splitting）**：
同一个活动标签在不同上下文中扮演不同角色时，把它拆成 a₁, a₂, a₃……
拆完之后，模型和实地每一步都可逆验证——互模拟恢复了。

集末用 "Just Cheese Please!" 三明治实战验证：前缀自动机→标签拆分→精确 Petri 网。
并用四种力框架诚实地点出区域挖掘的代价：追求结构保真，但害怕噪声、牺牲泛化。

## 关键术语

| 中文 | English | 简述 |
|------|---------|------|
| 迁移系统 | Transition System (TS) | 状态+迁移的有向图，状态的集合代表"到目前为止看到了什么" |
| 状态抽象 | State Abstraction | 序列/集合/多重集：用不同粒度总结历史 |
| n尾抽象 | n-tail Abstraction | 只看最近 n 步（1-tail=只看上一步） |
| 基于状态的区域 | State-Based Region | 一组状态，所有同类活动的箭头行为一致 |
| 极小区域 | Minimal Region | 不可再分的非平凡区域 → Petri网库所 |
| 模拟 | Simulation | 模型能做的系统都能做（单向） |
| 互模拟 | Bisimulation | 模型和系统每一步都可互相模拟（双向等价） |
| 标签拆分 | Label Splitting | 同一标签在不同上下文拆成 a₁, a₂, ... 以恢复互模拟 |
