# 播客节目说明：第02集 - 玩转“令牌游戏”：BPMN 流程建模普通话

## 简介
欢迎收听《BPM 流程解码》第二期！
上周我们聊了什么是业务流程管理，这一集我们正式进入“流程建模”的大门。你是否见过各种各样、五花八门的业务流程图？市场部画椭圆，研发部画3D方块，财务部甚至画云朵和闪电，彼此之间谁也看不懂谁……
为了终结这种“沟通巴别塔”灾难，业界制定了国际通用的“流程图普通话”——**BPMN 2.0 (业务流程模型和标注)**。今天，我们将用极其生动、好玩的**“令牌游戏 (Token Game)”**，带你在脑海中把静态的业务流程图变成流动的流水线，彻底掌握任务、序列流、开始/结束事件以及网关（XOR 与 AND）的底层语义，并现场带你拆解两道期末必考的建模大题！

## 学习目标
- **掌握 BPMN 四大基本元素**：任务 (Task)、序列流 (Sequence Flow)、开始事件 (Start Event)、结束事件 (End Event)。
- **理解“令牌游戏 (Token Game)”**：通过“蓝色小弹珠”在流程图中的物理移动，动态理解“流程实例 (Process Instance)”的生命周期。
- **玩转两大核心网关 (Gateway)**：
  - **排他网关 (XOR Gateway)**：掌握 Split 的“互斥且完备 (Mutually Exclusive & Complete)”数学逻辑，以及默认流 (Default Flow) 的兜底机制。
  - **并行网关 (AND Gateway)**：理解 Split 的“复制克隆”机制，以及 Join 的“同步等待 (Synchronization)”机制。
- **识别建模坏习惯**：明白为什么“隐式网关 (Implicit Gateway)”在建模中属于不良实践 (Bad Practice)，并学会在反馈循环 (Loop) 的入口老老实实加上 XOR Join 网关。
- **期末考题实战**：学会如何画出“信用风险评估 (Credit Risk Assessment)”与“保险理赔循环 (Insurance Claims Loop)”的控制流。

## 关键术语表
- **BPMN 2.0 (业务流程模型和标注)**：由 OMG 发布的 ISO 19510 国际标准，用于衔接组织业务设计与应用系统设计。
- **Task (任务)**：流程图中无法再拆分的具体工作步骤，画为圆角长方形。
- **Sequence Flow (序列流)**：描述控制流方向的实线箭头。
- **Start / End Event (开始/结束事件)**：流程实例的启动与终结标志，分别画为细边圆圈和粗边圆圈（Option 1 与 Option 2 规则不能混用）。
- **Token (令牌)**：用于在概念上跟踪流程执行进度的“虚拟筹码/蓝色小弹珠”。
- **Exclusive (XOR) Gateway (排他网关)**：非此即彼的选择路口，Split 分流只能也必须选一条，Join 汇合时来一个放一个。
- **Parallel (AND) Gateway (并行网关)**：多线并进的路口，Split 分流时克隆多颗弹珠同时出发，Join 汇合时执行同步等待。
- **Default Flow (默认流)**：作为 XOR Split 条件不满足时的兜底分流分支，带有斜杠标记。
- **Implicit Gateway (隐式网关)**：不画菱形网关直接分流或汇合，因容易产生歧义而被视为 Bad Practice。
