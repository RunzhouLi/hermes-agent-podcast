## 简介 / Summary

本集讲解 BPMN 中四个关键高级构件，帮助建模者超越基础顺序流，表达更真实的业务场景：

1. **事件网关**（Event-Based Gateway）：当流程需要等待外部世界先发生某个事件，再决定走哪条路。
2. **BPMN 数据**（Data Object / Data Store / Data Association）：表达流程读写的信息，区分实例级数据与持久化数据，区分数据关联与顺序流。
3. **子流程**（Sub-process）：通过折叠/展开管理流程复杂度，支持层级嵌套、循环、多实例、临时执行模式；区分嵌入式与可复用调用活动；事件子流程处理运行时异常与升级。
4. **定时事件**（Timer Events）：包括定时开始事件、中间定时等待事件和边界定时事件（中断型/非中断型）。

贯穿全集的稳定类比：**客服工单系统**——等待客户回复（事件网关）、记录工单信息（数据）、折叠投诉处理步骤（子流程）、SLA 超时升级（边界定时事件）。

## 关键术语 / Key Terms

| 中文 | English | 简要定义 |
|---|---|---|
| 事件网关 | Event-Based Gateway | 等待第一个外部事件决定路径；另一方做决定；排他且延迟 |
| 数据对象 | Data Object (DO) | 活动使用或产生的信息；属于当前流程实例 |
| 数据集合 | Data Collection | 一组数据对象；如二十份订单构成一个数据集合 |
| 数据存储 | Data Store (DS) | 持续存在、跨流程实例的信息存储（如数据库） |
| 数据关联 | Data Association | 虚线；读写数据；不推动流程执行 |
| 顺序流 | Sequence Flow | 实线；携带控制令牌；推动流程向前 |
| 折叠子流程 | Collapsed Sub-process | 隐藏内部的子流程；底部 + 标记 |
| 展开子流程 | Expanded Sub-process | 显示完整内部流程的子流程框 |
| 调用活动 | Call Activity (CA) | 调用外部定义的可复用流程/任务；加粗边框 |
| 事件子流程 | Event Sub-process | 父流程运行中由事件触发的内部处理；整个外框为虚线 |
| 循环子流程 | Loop Sub-process | 按条件反复执行；↺ 标记 |
| 多实例子流程 | Multi-instance Sub-process | 运行 n 次独立实例；∥ 标记 |
| 临时子流程 | Ad-hoc Sub-process | 指定可执行活动，不规定顺序；∼ 标记；内部无开始/结束事件 |
| 定时开始事件 | Timer Start Event | 按时间或周期启动流程实例 |
| 中间定时事件 | Intermediate Timer Catch Event | 流程中途等待时间条件满足 |
| 边界定时事件 | Boundary Timer Event | 附着在活动上的超时/截止处理 |
| 中断型 | Interrupting | 取消当前活动；边界事件圆圈实线 |
| 非中断型 | Non-interrupting | 保留当前活动，开启并行路径；边界事件圆圈虚线（注：此虚线为小圆圈线型，与事件子流程整个外框虚线含义不同） |

## 本集大纲 / Episode Outline

1. **开场与导航**（约 3 分钟）
   - 晓雨提出四个真实建模问题，B 引出本集四个工具
   - 建立客服工单系统稳定类比

2. **事件网关**（约 8 分钟）
   - 语义三要点：排他、另方决定、等第一个事件
   - 与 XOR 网关的对比：数据驱动 vs 事件驱动，立即 vs 延迟
   - 语法：后接中间捕获事件，不能直接接任务
   - 示例：报价发出后等待客户回应（购买/拒绝/两周超时）

3. **BPMN 数据**（约 7 分钟）
   - 四种数据类型：隐藏数据、数据对象、数据集合、数据存储
   - 数据关联 vs 顺序流：虚线不携带令牌，实线携带令牌
   - 数据对象为引用，可在图中多处复制以避免连线混乱
   - 数据选择性建模原则
   - 示例：库存检查流程（采购订单 + 仓库数据库 + 订单数据库）

4. **中段微总结**（约 1 分钟）

5. **子流程基础**（约 12 分钟）
   - 为什么需要子流程：可读性、抽象、特殊模式、作用域
   - 30–40 元素经验规则
   - 折叠 vs 展开：显示差异，语义相同
   - 执行语义：令牌进入→内部开始→内部结束→令牌继续
   - 子流程 vs 池/泳道：层级结构 vs 参与者责任
   - 展开可跨泳道，折叠不能
   - 数据作用域：按层级，外层可见内层，内层不可见外层
   - 子流程与消息，与数据，层级嵌套
   - 嵌入式 vs 调用活动：代码块 vs 函数调用
   - 事件子流程：虚线外框，父流程运行中由事件触发
   - 课后思考题：W04-D03-S051 最少元素问题

6. **子流程进阶**（约 8 分钟）
   - 循环子流程（↺）：while 条件；政府部长级查询例子
   - 多实例子流程（∥）：n 次实例；批改考卷例子
   - 临时子流程（∼）：活动已知，顺序自由；写书章节例子
   - 标记组合规则：↺ 和 ∥ 不能同时使用；补偿标记留待后续集

7. **定时事件**（约 8 分钟）
   - 定时开始事件：法庭每月触发例子
   - 中间定时事件：流程等待站；开庭前 1 周例子
   - 边界定时事件：附着活动的超时处理
   - 中断型 vs 非中断型：取消 vs 并行通知；虚线区分说明
   - 与练习 3（供应商/零售商 48 小时超时）整合示例

8. **综合类比与整合**（约 3 分钟）
   - 完整客服工单流程：四个工具协同

9. **五大常见混淆快速澄清**（约 3 分钟）

10. **总结与 EP05 预告**（约 2 分钟）
    - EP05：边界事件全家族、错误事件、终止事件、补偿
