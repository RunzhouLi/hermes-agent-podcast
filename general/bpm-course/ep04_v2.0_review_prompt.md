### 1. 课程覆盖 (Coverage)
- 对比 extracted.md 和 course_map.md，列出本集是否覆盖了所有教学幻灯片中的核心概念

### 2. 术语 (Terminology)
- 核心 English terms 是否在首次出现时完整介绍了"中文 → English → abbreviation → 通俗解释"
- 重点检查: Event-Based Gateway, Data Association, Call Activity, Event Sub-process, Interrupting/Non-interrupting

### 3. 正确性 (Correctness)
- 是否存在 BPMN 概念混淆或错误
- 特别检查最易混淆的五对概念是否被正确区分

### 4. 启发式教学深度 (Heuristic Teaching Depth)
- 每个核心概念是否有 Phase 1 (困惑) → Phase 2 (探索) → Phase 3 (框架) → Phase 4 (锚定) 的节奏
- Host A 是否作为发现催化剂而非仅提问
- 段间过渡是否使用了因果桥接而非清单式过渡

### 5. 可听性 (Listenability)
- 对话是否自然，适合中文播客
- 是否有论文式长句或"如图所示"等不适配音频的表达
- 客服工单类比是否贯穿全程

### 6. 发布风险
- 是否有不适合公开发布的内容
- 引用源材料是否清晰标注
- 是否存在明显幻觉或与源材料矛盾的内容
