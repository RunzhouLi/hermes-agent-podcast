## CRITICAL METHODOLOGY RULES

### 1. Heuristic 4-Phase Teaching (APPLY TO EVERY MAJOR CONCEPT)
- **Phase 1:** Host A encounters real problem
- **Phase 2:** Host B asks "How would YOU solve it?" — Host A tries and partially fails
- **Phase 3:** Host B gives framework ONLY after exploration
- **Phase 4:** Host A restates in own words + ties to analogy

### 2. Architectural Anchoring — NO checklist transitions
- Every transition: causal bridge explaining WHY next topic follows logically
- Reference central analogy at EVERY major transition (≥4-5 times)

### 3. Host A as Discovery Catalyst
- MUST try to figure things out before B answers
- After dense clusters: A restates or asks natural question
- NO empty praise ("太厉害了", "太神奇了")

### 4. Pacing: ~15% intro / ~65-70% content / ~15% recap per concept

### 5. Bilingual Terminology Protocol
For EVERY core term: 中文 → English → abbreviation → plain explanation → example

### 6. Stable Analogy
Use **"舞台剧" (stage play)** analogy from the episode plan:
- 流程像一场已经开演的舞台剧
- 终止事件 = 演出中途拉幕宣布停演
- 事件子流程 = 临时加演节目
- 边界事件 = 后台随时可能触发的事故处理流程
- 错误事件 = 台上演砸了，后台急救方案
- 补偿 = 已经演完的一幕需要"返场补救"（退票退款）
- 文本注释 = 剧本旁边的批注
